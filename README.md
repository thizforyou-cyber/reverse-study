# June 2026 Public Administration PYQ Practice

A focused practice website containing only the June 2026 UGC NET/JRF Public Administration question set.

## Included
- 90 questions, numbered Q.51–Q.140, imported from the supplied `2026 JUNE.docx`.
- Original question wording, options, numbering and supplied answer keys retained.
- Instant answer feedback, session accuracy, bookmarks and mistake review.
- Question-specific Google searches and official/academic-source search links to help study and independently verify each answer.
- Responsive, minimal interface.

## Source limitations
The supplied document contains 90 questions (Q.51–Q.140), not a complete 100-question set. It does not provide verified unit labels or detailed explanations for each question. These have not been invented. The displayed answer is the key supplied in the document, not an independently authenticated official key.

## Run locally
Open `index.html` in a browser. For PWA installation and service-worker caching, serve the folder over HTTPS (for example, GitHub Pages).
